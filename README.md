# PHEONIX — Haute Atelier & Surrealist Wear

Avant-garde haute couture house and modern aesthetic clothing store. Engineered with a **mobile-first cinematic architecture** inspired by Denis Villeneuve (*Blade Runner 2049* / *Dune*) and Jonathan Glazer (*Under the Skin*).

Repository: [https://github.com/rishav00roy-web/pheonix](https://github.com/rishav00roy-web/pheonix)

---

## Tech Stack
- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS (Dark obsidian void, editorial typography: *Syne*, *Cinzel*, *Space Mono*)
- **Icons**: Lucide React
- **Audio & Haptics**: Web Audio API (Atmospheric sub-bass runway drone and UI haptics)
- **Effects**: Canvas Confetti

---

## Architectural Highlights
1. **Cinematic Mobile-First Hero**:
   - Monolithic display typography (`PHEONIX`) framed by ambient slow-pulsing ember glows.
   - Interactive 3-Act narrative switcher (`ACT I: THE CHIMERA MAW`, `ACT II: SCULPTED MONOLITHS`, `ACT III: LIQUID ANATOMY`) with smooth editorial backdrop crossfades.
   - Instant touch navigation to 14 numbered artefacts and flagship inspection.
   - Swipeable horizontal category bar anchored to mobile viewport.

2. **14-Piece Wardrobe Collection**:
   - Mobile-First 2-Column compact grid vs. 1-Column full-width editorial runway mode.
   - Six distinct categories:
     - **Outerwear**: *Vortex Asymmetric Storm Trench*, *Vertebral Embossed Moto Jacket*, *Basalt Cocoon Sculpted Bomber*.
     - **Knits & Tops**: *Phoenix Ash Deconstructed Mohair*, *Hydra Anatomical Cut-Out Top*, *Chitin Cowl Monolith Hoodie*.
     - **Dresses**: *Liquid Obsidian Column Gown*, *Carapace Corset Mini Dress*.
     - **Trousers**: *Mantis Geometric Modular Trousers*, *Vertebral Slit Flared Japanese Denim*.
     - **Footwear**: *The Chimera Maw Stiletto*, *Leviathan Vertebral Platform Boot*.
     - **Accessories**: *Molten Spine Chest Harness*, *Eclipse Insectoid Chrome Shades*.

3. **Slide-Up Mobile Dossier Sheet**:
   - High-resolution editorial garment banner, architectural concept notes, technical composition details, and thumb-friendly size selectors.

4. **Acquisition Manifest (Cart Drawer)**:
   - Minimalist black slip for securing numbered allocations.

## Getting Started

```bash
# Clone the repository
git clone https://github.com/rishav00roy-web/pheonix.git

# Enter project directory
cd pheonix

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
